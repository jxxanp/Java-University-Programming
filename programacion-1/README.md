# Programación 1 — 2° Semestre (2025)

Proyectos desarrollados durante el segundo semestre de Ingeniería de Sistemas en la Universidad de Córdoba. El curso abarcó los fundamentos de la programación orientada a objetos en Java y la construcción de interfaces gráficas con Swing.

## Temas del curso

- Clases, objetos y encapsulamiento
- Constructores y métodos getter/setter
- Vectores y arrays de objetos
- Vectores en paralelo
- Interfaces gráficas con Swing y JFrame
- JTable y visualización de datos tabulares
- Métodos de búsqueda y ordenamiento
- Diagramas de clases UML

## Proyectos

| Proyecto | Descripción |
|---|---|
| [CalculadoraRacionales](./CalculadoraRacionales/) | Calculadora de números racionales con operaciones aritméticas y normalización por MCD |
| [TiendaOfertas](./TiendaOfertas/) | Sistema de compras con descuentos por volumen y cálculo de obsequios |
| [CuentaBancariaProject](./CuentaBancariaProject/) | Gestión de cuenta bancaria con depósitos, retiros, intereses e inversiones |
| [ConcesionarioProject](./ConcesionarioProject/) | Inventario de vehículos con búsqueda y control de disponibilidad |
| [TrabajadoresProject](./TrabajadoresProject/) | Gestión de trabajadores con vectores de objetos y GUI |
| [VectoresParalelos](./VectoresParalelos/) | Inventario de productos con vectores paralelos y tabla interactiva |
