# ParcialPractico

Ejercicio práctico de Java centrado en **interfaces funcionales propias, genéricos, expresiones lambda e iteradores**.

## Contenido
- Interfaz funcional `ReglaTarifa` para aplicar reglas de precio.
- Interfaz genérica `Criterio<T>` para filtrar elementos.
- Interfaz funcional `FormatoCurso` para definir formatos de salida.
- Recorrido de listas mediante `Iterator`.
- Expresiones lambda para criterios, tarifas y formatos.
- Reto integrador con reglas promocionales aplicadas a cursos.

## Estructura
```
ParcialPractico/
└── src/
    ├── Main.java
    ├── Criterio.java
    ├── Curso.java
    ├── FormatoCurso.java
    └── ReglaTarifa.java
```

## Ejecución
Abre la carpeta como proyecto Java en IntelliJ IDEA o compila los archivos de `src` con un JDK instalado. La clase principal es `Main`.
