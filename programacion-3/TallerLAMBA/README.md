# TallerLAMBA

Taller práctico sobre **interfaces funcionales y expresiones lambda** en Java.

## Contenido
- Interfaz funcional propia `OperacionPrecio`.
- Operaciones de precio mediante expresiones lambda.
- Filtrado de productos con `Predicate`.
- Transformación de datos con `Function`.
- Procesamiento de elementos con `Consumer`.
- Creación de objetos con `Supplier`.
- Composición de predicados y reto integrador.

## Estructura
```
TallerLAMBA/
└── src/
    ├── Main.java
    ├── OperacionPrecio.java
    └── Producto.java
```

## Ejecución
Abre la carpeta como proyecto Java en IntelliJ IDEA o compila los archivos de `src` con un JDK instalado. La clase principal es `Main`.
