# Programación 2 — 3° Semestre (2026)

Proyectos desarrollados durante el tercer semestre de Ingeniería de Sistemas en la Universidad de Córdoba. El curso profundizó en la programación orientada a objetos avanzada, estructuras de datos y patrones de diseño.

## Temas del curso

- Herencia simple y multinivel
- Polimorfismo y sobreescritura de métodos
- Clases abstractas e interfaces
- Jerarquías de herencia complejas
- Estructuras de datos: listas simplemente enlazadas
- Patrón de diseño MVC (Modelo-Vista-Controlador)
- Colecciones: ArrayList
- Interfaces gráficas avanzadas con Swing
